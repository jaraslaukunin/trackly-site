## Назначение сайта

Публичная часть Trackly используется как единая точка доступа к информации о проекте и юридическим документам.

Сайт может открываться пользователем самостоятельно или по ссылкам из мобильного/веб-приложения Trackly, в частности во время регистрации, входа в аккаунт и ознакомления с условиями использования сервиса.

Основные задачи сайта:

- Публикация политики конфиденциальности.
- Публикация согласия на обработку персональных данных.
- Публикация условий использования сервиса.
- Отображение публичного статуса доступности Trackly.
- Предоставление информации об операторе сервиса.
- Поддержка нескольких языков интерфейса.

## Локализация

Trackly поддерживает четыре варианта интерфейса. Переключение выполняется на стороне браузера без перезагрузки страницы.

| Код | Язык | Описание |
|---|---|---|
| `RU` | Русский | Основной русский вариант интерфейса |
| `EN` | English | Англоязычная версия сайта |
| `BY` | Беларуская | Беларуская мова ў афіцыйным правапісе |
| `BE` | Łacinka | Беларуская лацінка ў лацінізаванай тарашкевіцы |

Выбранный язык сохраняется в `localStorage`, поэтому при следующем посещении сайта интерфейс открывается на ранее выбранном языке.

## Локальный запуск

Для запуска сайта не нужно устанавливать зависимости или выполнять сборку. Можно открыть файл `index.html` напрямую в браузере.

Для более корректной проверки переходов, скриптов и запросов рекомендуется поднять простой локальный HTTP-сервер.

### Вариант 1. Через Node.js

```bash
npx serve .
```

### Вариант 2. Через Python

```bash
python3 -m http.server 8080
```

После запуска откройте в браузере:

```text
http://localhost:8080
```

## Статус сервиса

Страница статуса доступна по адресу:

```text
[https://tracklyapp.xyz/status.html](https://tracklyapp.xyz/status.html)
```

Она предназначена для быстрой проверки основных компонентов, необходимых для работы Trackly:

- доступности публичного сайта;
- доступности Supabase Edge Functions;
- корректного ответа health-check endpoint;
- общего состояния серверной части приложения.

> Страница статуса показывает техническую доступность отдельных компонентов, но не гарантирует отсутствие временных ограничений, ошибок отдельных функций или проблем на стороне сети пользователя.
